## What is a Cohort?

A cohort is a group of users who share a common characteristic or experience within a defined time period. In this analysis:

- **Cohorts are defined by signup month**: Customers who made their first purchase in the same month belong to the same cohort
- **Cohort analysis tracks behavior**: We monitor how each cohort retains customers over time
- **Comparison across cohorts**: Enables comparison of different time periods to identify trends

## Why is Cohort Retention Useful?

Cohort retention analysis provides several key business insights:

1. **Customer Behavior Patterns**: Understand how customer engagement evolves over time
2. **Acquisition Effectiveness**: Evaluate which time periods/strategies brought in higher-value customers
3. **Product Impact**: Measure how product changes affect retention across different cohorts
4. **Lifetime Value Estimation**: Inform customer lifetime value (CLV) calculations
5. **Churn Prediction**: Identify at-risk cohorts and timeframes
6. **Marketing Optimization**: Allocate resources to improve retention in underperforming cohorts

## SQL Implementation Details

The project includes a complete SQL-based implementation using SQLite:

### SQL-based Script (`cohort_retention_sql.py`)

This script performs the entire analysis using actual SQL queries executed against a SQLite database:

1. **Database Creation**: Creates `online_retail.db` SQLite database with the dataset
2. **SQL Execution**: Executes complex SQL queries using Common Table Expressions (CTEs)
3. **Results Processing**: Loads SQL results into pandas for visualization
4. **Complete SQL Workflow**: Demonstrates end-to-end SQL-based cohort analysis

### SQL Query Structure

The SQL implementation uses three main CTEs:

```sql
WITH customer_cohorts AS (
    -- Identify first purchase month per customer
    SELECT CustomerID, MIN(DATE(InvoiceDate)) AS cohort_month
    FROM online_retail
    GROUP BY CustomerID
),
cohort_counts AS (
    -- Count customers per cohort and time period
    SELECT cohort_month, cohort_index, COUNT(DISTINCT CustomerID) AS customer_count
    FROM online_retail
    JOIN customer_cohorts ON CustomerID = CustomerID
    GROUP BY cohort_month, cohort_index
),
cohort_sizes AS (
    -- Get initial cohort sizes
    SELECT cohort_month, customer_count AS cohort_size
    FROM cohort_counts
    WHERE cohort_index = 0
)
-- Final query calculates retention rates
SELECT cohort_month, cohort_index, cohort_size, customer_count,
       ROUND((customer_count * 100.0 / cohort_size), 2) AS retention_rate
FROM cohort_counts
JOIN cohort_sizes ON cohort_month = cohort_month
ORDER BY cohort_month, cohort_index
```

### Reference SQL Queries (`cohort_queries.sql`)

The project also includes reference SQL queries that show how the analysis would be implemented in a standard SQL database. These are generated by the pandas script for documentation purposes.

### Query 1: Customer Cohort Identification
```sql
WITH customer_cohorts AS (
    SELECT 
        CustomerID,
        MIN(DATE(InvoiceDate, 'start of month')) AS cohort_month
    FROM online_retail
    GROUP BY CustomerID
)
```

### Query 2: Cohort Count Calculation
```sql
SELECT 
    cc.cohort_month,
    -- Calculate months since signup
    CAST(strftime('%Y', DATE(InvoiceDate, 'start of month')) AS INTEGER) * 12 + 
    CAST(strftime('%m', DATE(InvoiceDate, 'start of month')) AS INTEGER) -
    (CAST(strftime('%Y', cc.cohort_month) AS INTEGER) * 12 + 
     CAST(strftime('%m', cc.cohort_month) AS INTEGER)) AS cohort_index,
    COUNT(DISTINCT o.CustomerID) AS customer_count
FROM online_retail o
JOIN customer_cohorts cc ON o.CustomerID = cc.CustomerID
GROUP BY cc.cohort_month, cohort_index
```

### Query 3: Retention Rate Computation
```sql
WITH cohort_counts AS (
    SELECT 
        cohort_month,
        cohort_index,
        customer_count,
        FIRST_VALUE(customer_count) OVER (PARTITION BY cohort_month ORDER BY cohort_index) AS cohort_size
    FROM (
        -- Subquery from Query 2
    )
)
SELECT 
    cohort_month,
    cohort_index,
    cohort_size,
    customer_count,
    ROUND((customer_count * 100.0 / cohort_size), 2) AS retention_rate
FROM cohort_counts
```

## Technical Approach

### Cohort Index Calculation
The cohort index represents the number of months since a customer's first purchase:
- Month 0: First purchase month (signup month)
- Month 1: One month after signup
- Month 2: Two months after signup
- And so on...

### Retention Rate Formula
```
Retention Rate = (Customers in cohort at month N / Initial cohort size) × 100
```

### Consistent Retention Windows
- All cohorts are measured using the same time windows (0, 1, 2, 3... months)
- This ensures fair comparison across different signup periods
- Seasonal effects can be identified by comparing cohorts across different months
